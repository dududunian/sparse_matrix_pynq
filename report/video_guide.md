# 演示视频拍摄指南

平台要求（按提交页截图）：MP4，AVC/H.264，时长不超过 3 分钟，大小不超过 300 MB。建议录制 2 分 40 秒，1920×1080、30 fps，视频码率 6～8 Mbps，音频 AAC 128 kbps；预计约 125～165 MB。导出后检查编码，不能仅改扩展名。

## 拍摄前

1. 板卡通电、SD 启动，电脑网线连接，打开新 matrix_demo.ipynb。关闭其他运行 FPGA 的 Notebook。
2. 运行界面单元；先彩排一次：32 阶、零元素 90%、种子 2026、随机输入、稀疏矩阵乘法，生成→加载→计算。
3. 隐藏浏览器书签、聊天通知、学校标识、教师姓名、桌面个人信息。板上不得露出学校资产标签；不拍学生证、校服标识。
4. 使用系统录屏或已有录屏软件，麦克风试音。开头用手机横屏拍板卡和网线、电源连接约 10 秒，再接屏幕录制。全片横屏，字幕清晰。

## 不要说错

- 50 MHz 是目标时钟；49.999 MHz 是寄存器读回，不是外部仪器测量。
- FPGA 内部耗时不等于端到端耗时；没有公平 CPU 基线，不说“比 CPU 快多少倍”。
- 当前数据通路是 AXI4-Lite/MMIO，未实现 DMA 或 PL 直连 DDR。
- 不把旧版本动态三例、完整移植验收、UI 六例混成一次测试。
- 实际计算片段尽量连续保留，从生成到启动、结果显示不要跳切；等待较久可明确注明加速播放。
- 最新完整板测先跑完再拍；不要只录之前静态输出并称为现场计算。

文件建议命名 demo_video.mp4。用播放器完整回看确认总时长≤180 秒，声音清晰，画面中无学校及教师信息。
